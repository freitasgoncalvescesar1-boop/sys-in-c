

===============================================================================
     JAIL 3.0 - HERMETIC DEFAULT-DENY SANDBOX & CAPABILITY GRANTS MODEL
===============================================================================

1. OVERVIEW & PHILOSOPHY
-------------------------------------------------------------------------------
JAIL 3.0 is an enterprise-grade Linux process sandbox built on a pure 
Default-Deny Whitelist architecture.

By default, any process spawned inside JAIL operates in complete hermetic 
lockdown (0 permissions granted). The kernel permits only the bare-minimum 
compute syscalls (read, write to terminal, brk, mmap, futex, exit).

To allow specific operations (such as internet access, writing files, or 
spawning subprocesses), explicit capability unlock flags must be passed.


2. CAPABILITY GRANTS (UNLOCK FLAGS)
-------------------------------------------------------------------------------
- -N, --net       : Unlock network communication (sockets, DNS, HTTP, connect)
- -W, --write     : Unlock file creation and modification (unlink, chmod, mkdir)
- -E, --exec      : Unlock subprocess spawning (fork, vfork, clone, execve)
- -I, --ipc       : Unlock SysV IPC & shared memory
- -K, --signal    : Unlock signal injection & kill tampering
- -A, --all       : Unlock all capabilities (unrestricted / permissive mode)
- --kill          : Kill process immediately on unauthorized syscall (SIGSYS)


3. ADVANCED MONITORING & AUDITING (-om & -nd)
-------------------------------------------------------------------------------
A. ONLY-MONITOR LOG DUMP (-om [FILE])
   - Records execution metrics, granted capabilities, CPU time, and exit status 
     into 'jail_audit.log' (or custom file).

B. NERD MODE (-nd / --nerd)
   - Displays real-time hardware telemetry:
     * CPU Architecture context.
     * User vs System CPU execution ticks.
     * Voluntary / Involuntary context switches.
     * Peak Resident Set Size (RSS) memory consumption and page faults.


4. EXAMPLES
-------------------------------------------------------------------------------
- Pure Isolated Computation (No net, no disk write, no subprocesses):
  $ jail -- ./calc 10 + 20

- Grant Network Access Only:
  $ jail -N -- ./httpget http://google.com

- Grant Network + Disk Write Access:
  $ jail -NW -- ./httpget -o site.html http://google.com

- Grant Subprocess Execution (Shell):
  $ jail -E -- /bin/sh -c "whoami"
