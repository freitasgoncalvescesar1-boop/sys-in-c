===============================================================================
            FREESTANDING FIXED-POINT MATHEMATICS (KFIXED)
===============================================================================

1. OVERVIEW
-------------------------------------------------------------------------------
KFIXED is a zero-dependency, 16.16 fixed-point arithmetic library for OS 
kernels, bare-metal bootloaders, and embedded systems.

It performs fractional calculations using 32-bit and 64-bit integer instructions,
eliminating reliance on hardware Floating Point Units (FPU) or C runtime math 
libraries (libm).


2. DATA TYPE & FORMAT
-------------------------------------------------------------------------------
- Type: fp32_t (int32_t)
- Format: 16.16 (16-bit signed integer part, 16-bit fractional part)
- Scale Factor: 2^16 = 65536
- Range: -32768.0 to +32767.99998


3. API SPECIFICATION
-------------------------------------------------------------------------------

A. CONVERSION UTILITIES
   - fp32_t fp32_from_int(int i);
     Converts a 32-bit integer to 16.16 fixed-point format.

   - int fp32_to_int(fp32_t fp);
     Truncates a 16.16 fixed-point value to an integer.

   - size_t fp32_to_str(fp32_t fp, char *buf, size_t max_len, int decimals);
     Formats a fixed-point value into a decimal ASCII string without libc.

B. ARITHMETIC OPERATIONS
   - fp32_t fp32_add(fp32_t a, fp32_t b);
   - fp32_t fp32_sub(fp32_t a, fp32_t b);
   - fp32_t fp32_mul(fp32_t a, fp32_t b);
   - fp32_t fp32_div(fp32_t a, fp32_t b);
   - fp32_t fp32_abs(fp32_t a);

C. TRANSCENDENTAL FUNCTIONS
   - fp32_t fp32_sqrt(fp32_t a);   /* Fixed-point square root */
   - fp32_t fp32_sin(fp32_t rad);  /* Taylor series sine approximation */
   - fp32_t fp32_cos(fp32_t rad);  /* Taylor series cosine approximation */


4. BARE-METAL USAGE EXAMPLE
-------------------------------------------------------------------------------

#include "kfixed.h"

void kernel_math_demo(void) {
    fp32_t x = fp32_from_int(10);
    fp32_t y = fp32_from_int(3);

    fp32_t quotient = fp32_div(x, y);       /* 10 / 3 = 3.3333 */
    fp32_t root = fp32_sqrt(fp32_from_int(64)); /* sqrt(64) = 8.0 */

    char str[32];
    fp32_to_str(quotient, str, sizeof(str), 4);
}
